Sval has shortcuts of its own for the Launcher, the Workspace panel, pins, Splits,
Favorites, and Peeks. Sval also changes some everyday shortcuts.
Each shortcut below is given for macOS first, then for Windows and Linux.
Settings › Keyboard shortcuts lists every shortcut, and you can change most
of them there.

**None** means the command has no shortcut until you give it one.

## The Launcher

| Command | macOS | Windows and Linux |
|---|---|---|
| Open the Launcher | <kbd>⌘L</kbd> | <kbd>Ctrl+L</kbd> or <kbd>Alt+D</kbd> |
| Open in a new tab | <kbd>⇧Enter</kbd> | <kbd>Shift+Enter</kbd> |
| Open in a new window | <kbd>⇧⌘Enter</kbd> | <kbd>Ctrl+Shift+Enter</kbd> |
| Open next to this tab in a Split | <kbd>⌥Enter</kbd> | <kbd>Alt+Enter</kbd> |
| Remove a History or Search suggestions row | <kbd>⇧⌫</kbd> | <kbd>Shift+Delete</kbd> or <kbd>Shift+Backspace</kbd> |

The last four shortcuts work on the selected row. They work in the
Launcher and in the search field on the home page.

## The Workspace panel

| Command | macOS | Windows and Linux |
|---|---|---|
| Show or hide the Workspace panel | <kbd>⌃Z</kbd> | <kbd>Ctrl+Alt+Z</kbd> |
| New Workspace | None | None |
| Move between the address bar, the Workspace panel and the page | <kbd>F6</kbd>, or <kbd>⇧F6</kbd> to go back | <kbd>F6</kbd>, or <kbd>Shift+F6</kbd> to go back |
| Undo closing tabs or deleting a group, while the Undo message shows | <kbd>⌘Z</kbd> | <kbd>Ctrl+Z</kbd> |

These keys work while a row in the Workspace has focus. On a Mac, Alt is
the <kbd>⌥</kbd> key and Ctrl is the <kbd>⌃</kbd> key.

| Command | Key |
|---|---|
| Next row, previous row | <kbd>↓</kbd>, <kbd>↑</kbd> |
| First row, last row | <kbd>Home</kbd>, <kbd>End</kbd> |
| Extend the selection down or up | <kbd>Shift+↓</kbd>, <kbd>Shift+↑</kbd> |
| Select or deselect the row | <kbd>Ctrl+Space</kbd> |
| Clear the selection | <kbd>Esc</kbd> |
| Go to a row by its name | Type its first letters |
| Open a group | <kbd>→</kbd> |
| Close a group, or go to the row's group | <kbd>←</kbd> |
| Next pane in a Split, previous pane in a Split | <kbd>→</kbd>, <kbd>←</kbd> |
| Show the tab, or open or close the group | <kbd>Enter</kbd> or <kbd>Space</kbd> |
| Rename | <kbd>F2</kbd> |
| Close the tab, or delete the group | <kbd>Delete</kbd> or <kbd>Backspace</kbd> |
| Move up, move down | <kbd>Alt+↑</kbd>, <kbd>Alt+↓</kbd> |
| Move into the group above | <kbd>Alt+→</kbd> |
| Move out of its group | <kbd>Alt+←</kbd> |
| Move the pane left or right in its Split | <kbd>Alt+←</kbd>, <kbd>Alt+→</kbd> |
| Open the row's menu | <kbd>Shift+F10</kbd> or the Menu key |
| Widen or narrow the Workspace panel, on its edge | <kbd>←</kbd>, <kbd>→</kbd> |

In the Workspaces list, <kbd>Shift+Enter</kbd> opens the selected Workspace
in a new window.

## Favorites

| Command | macOS | Windows and Linux |
|---|---|---|
| Add the page to Favorites | <kbd>⌘D</kbd> | <kbd>Ctrl+D</kbd> |
| Show Favorites | <kbd>⇧⌘O</kbd> | <kbd>Ctrl+Shift+O</kbd> |
| Open a favorite's menu, in the Favorites menu | <kbd>⇧F10</kbd> or the Menu key | <kbd>Shift+F10</kbd> or the Menu key |

Show Favorites opens the Favorites menu.

## Pins

| Command | macOS | Windows | Linux |
|---|---|---|---|
| Go to pin 1 to 9 | <kbd>⌘1</kbd> to <kbd>⌘9</kbd> | <kbd>Ctrl+1</kbd> to <kbd>Ctrl+9</kbd> | <kbd>Alt+1</kbd> to <kbd>Alt+9</kbd> |
| Move between pins on the home page | Arrow keys | Arrow keys | Arrow keys |
| Move a pin left on the home page | <kbd>⌃⇧←</kbd> | <kbd>Ctrl+Shift+←</kbd> | <kbd>Ctrl+Shift+←</kbd> |
| Move a pin right on the home page | <kbd>⌃⇧→</kbd> | <kbd>Ctrl+Shift+→</kbd> | <kbd>Ctrl+Shift+→</kbd> |

While you hold <kbd>⌘</kbd> (Ctrl on Windows, Alt on Linux), each pin shows
its number. In a private window and in an agent's Workspace, the keys for
pin 1 to 9 go to tabs instead.

## Tabs, windows, and pages

| Command | macOS | Windows and Linux |
|---|---|---|
| New tab | <kbd>⌘T</kbd> | <kbd>Ctrl+T</kbd> |
| Copy the page's address | <kbd>⇧⌘C</kbd> | <kbd>Ctrl+Shift+C</kbd> |
| Recent tabs | <kbd>⌃Tab</kbd> | <kbd>Ctrl+Tab</kbd> |
| Previous tab in the Workspace | <kbd>⌃⇧Tab</kbd> | <kbd>Ctrl+Shift+Tab</kbd> |
| New window | <kbd>⌘N</kbd> | <kbd>Ctrl+N</kbd> |
| New private window | <kbd>⇧⌘N</kbd> or <kbd>⇧⌘P</kbd> | <kbd>Ctrl+Shift+N</kbd> or <kbd>Ctrl+Shift+P</kbd> |
| Reopen Last Closed Tab | <kbd>⇧⌘T</kbd> | <kbd>Ctrl+Shift+T</kbd> |
| Reopen Last Closed Window | None | None |
| New Peek Window | <kbd>⌥⌘N</kbd> | <kbd>Ctrl+Alt+N</kbd> |
| Split the tab, or add a pane to its Split | <kbd>⌃+</kbd> | <kbd>Ctrl+Shift+Plus</kbd> |
| Separate the Split | None | None |
| Show or hide history | <kbd>⇧⌘H</kbd> | <kbd>Ctrl+H</kbd> |
| Show history | <kbd>⌘Y</kbd> | <kbd>Ctrl+Shift+H</kbd> |
| Reader View | <kbd>⌥⌘R</kbd> | <kbd>F9</kbd> on Windows, <kbd>Ctrl+Alt+R</kbd> on Linux |
| Remove from this site | None | None |
| Snip | None | None |
| Colorshift this site | None | None |

- **New tab.** The new tab opens at the top of the Workspace's list.
- **Recent tabs.** You switch to the tab you used last in this Workspace. With
  three or more tabs in the Workspace, holding <kbd>⌃</kbd> (Ctrl) opens a
  grid of every tab over the page, the most recently used first. The grid has
  a heading that names the Workspace, and a footer that shows some of the keys
  you can press and what each one does. <kbd>Tab</kbd> and the arrow keys move
  the choice through the grid. While the grid is open, <kbd>⌃\`</kbd>
  (<kbd>Ctrl+\`</kbd>) moves the choice back one tab, as <kbd>⌃⇧Tab</kbd>
  (<kbd>Ctrl+Shift+Tab</kbd>) does. Here \` means the key above
  <kbd>Tab</kbd>. With the grid closed, the page gets <kbd>⌃\`</kbd>
  (<kbd>Ctrl+\`</kbd>). Letting go of <kbd>⌃</kbd> (Ctrl) switches to the
  chosen tab, and so does a click on a tab. <kbd>Esc</kbd> closes the grid and
  leaves you on the tab you're on. <kbd>⌃W</kbd> (Ctrl+W) closes the chosen
  tab. When recently used order is turned off, <kbd>⌃Tab</kbd> (Ctrl+Tab) goes
  to the next tab in the Workspace.
- **New window.** The new window shows the next Workspace in your list.
- **Reopen Last Closed Tab.** If the last thing you closed was a window,
  the window comes back. Otherwise, you get back the tab you closed last
  in this Workspace, in this window.
- **New Peek Window** on Windows. Some keyboard layouts type a character
  with Ctrl+Alt+N. With those layouts, the key types that character
  instead.
- **Split the tab.** The tab you're on splits, or gets a new pane in its
  Split. On a Mac, the shortcut is <kbd>⌃</kbd> with the key that types +.
  On a US layout, that's <kbd>⌃⇧=</kbd>. On Windows and Linux,
  <kbd>Ctrl+Shift+=</kbd> types Plus, so it splits the tab. There,
  <kbd>Ctrl+=</kbd> zooms in.
- **Show history** and **Show or hide history** open the History sidebar.

## Links

| Command | macOS | Windows and Linux |
|---|---|---|
| Open a link in a Quick Peek | <kbd>⌥</kbd>-click | <kbd>Alt</kbd>+click |

- **Open a link in a Quick Peek.** You can change the click to
  <kbd>⌥⌘</kbd>-click or <kbd>⇧⌥</kbd>-click (Ctrl+Alt+click or
  Shift+Alt+click on Windows and Linux). With either click, the link opens
  in a Quick Peek where the click would otherwise open a new tab or window.
  <kbd>⌘</kbd>-click, <kbd>⇧</kbd>-click, <kbd>⇧⌘</kbd>-click, and
  middle-click keep opening new tabs and windows, so they can't open a
  Quick Peek. On Windows and Linux, those clicks are Ctrl+click, Shift+click,
  Ctrl+Shift+click, and middle-click.

  and Ctrl+Shift+D) open nothing in Sval. Sval has Favorites in place of
  bookmarks.

## Keys a website can't take

A website can't use these keys for itself, even after you change them:

- Open the Launcher, New Workspace, New Peek Window, and Copy the page's
  address.
- Go to a pin, Split the tab, and Separate the Split.
- Remove from this site, Snip, and Colorshift this site.
- <kbd>F6</kbd> and <kbd>Shift+F6</kbd>.
- Show or hide the Workspace panel, on Windows and Linux. On a Mac, websites get
  <kbd>⌃Z</kbd>, so a terminal in a web page can use that key.
- New tab, New window, New private window, Close tab, Close window, and
  Quit.

While you're on a website, it can take the other shortcuts. For example, a
web app can use <kbd>⌘D</kbd> for itself. Menus show the shortcut next to
each command that has one. That includes the menus you open by
right-clicking a tab, a page, or a text field.

## Settings › Keyboard shortcuts

<Screenshot name="docs-keyboard-shortcuts" alt="Settings › Keyboard shortcuts: the Launcher group, then the Workspace panel group with the ⌃Tab and swipe switches above its shortcuts, with Change and Clear next to the shortcuts you can change" />

- The groups list every shortcut. First come the Launcher, the Workspace
  panel, Favorites, Pins, and Links. Then come the groups for the rest of Sval's commands.
- The Workspace panel group has two switches above its shortcuts:
  - **Ctrl+Tab switches to recently used tabs.** The switch sets the order
    that <kbd>⌃Tab</kbd> (Ctrl+Tab) goes through your tabs. The switch is on
    by default, and it syncs to your other devices. On a Mac, the switch
    reads ⌃Tab.
  - **Swipe sideways over the Workspace panel to switch Workspaces.** While
    the switch is on, a sideways swipe or scroll over the Workspace panel
    moves the window to the next or previous Workspace. The switch is on by
    default, and it syncs to your other devices.
- **Change.** Sval waits for you to press the new shortcut, and the field
  shows **Press the new key**. <kbd>Esc</kbd>, <kbd>Tab</kbd>, or
  **Cancel** stops without a change.
  For **Open a link in a Quick Peek**, the field shows **Hold the keys and click
  here**. Sval takes the keys you hold when you click the field or press
  <kbd>Enter</kbd>. If Sval can't use that click, the field says why.
- **Clear.** The shortcut is removed and reads **None**. For **Open a link
  in a Quick Peek**, the click reads **Off**. Quick Peek turns off, and so
  does the switch in Settings › Links.
- **Reset.** The shortcut goes back to Sval's default. This button shows
  only for a shortcut you've changed.
- **Reset all shortcuts.** After you confirm, every shortcut goes back to
  its default.
- A row with no buttons has a fixed shortcut.
- **Your extensions add these shortcuts.** This group lists the shortcuts
  your extensions add. **Change in the extensions page** opens the page
  where you change those shortcuts.

Changed shortcuts stay on the device you changed them on. The click you
choose for **Open a link in a Quick Peek** stays on that device too. When you
clear the click, or choose one while it reads **Off**, the switch in
Settings › Links changes too. That switch syncs to your other devices.
