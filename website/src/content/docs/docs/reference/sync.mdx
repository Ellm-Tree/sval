Sval syncs through a folder you choose, and encrypts everything it puts
there with a key only your devices have. Settings › Sync and devices holds
the folder, this device's name, adding a device, and the sync key.

## Sync

The top row of the Sync card shows the sync indicator's icon and words,
then the buttons for the current state, with **Stop Syncing** last. The
first button is the most likely fix. The sync folder comes under the row.
While no folder is chosen, the Sync card offers three ways to sync.

- **A folder on this computer…** You choose a folder every device can
  reach, such as a folder in iCloud Drive.
- **A folder on an SMB server…** You sign in to a file server and name a
  folder on the server.
- **A folder in Dropbox…** You sign in to Dropbox and choose a Dropbox
  folder.
- **Sync folder.** The folder's name and place. For a cloud service Sval
  recognizes, like iCloud Drive or OneDrive, Sval shows the service's name
  and the folder's name.
- **Show in Finder** (**Show in File Explorer** on Windows, **Show in Files**
  on Linux). The folder opens in the file manager, for a folder on this
  computer only.
- **Change…** You choose another place to sync with. The place in use opens
  with the folder filled in.
- **Save a backup…** The button shows with "You haven't saved a backup of
  your sync key" until you save a backup.
- **Sync now.** Sval syncs straight away, and the Sync card says **Sval
  couldn't sync.** when the sync fails.
- **Stop Syncing.** After you confirm, this computer
  stops syncing and keeps every Workspace while Sval forgets the sign-in for
  an SMB server or Dropbox.

When something needs you, the Sync card names the problem and offers the
fix. In the table, *folder* stands for the sync folder's name.

| The Sync card says | Buttons |
|---|---|
| Can't reach *folder* | **Try again** |
| Sval can't find *folder* | **Choose folder…**, **Set up folder again** |
| Sval can't open *folder* | **Choose another folder…** |
| Sign in to Dropbox again | **Sign in to Dropbox…** |
| The SMB server didn't accept the sign-in | **Edit connection…** |
| Sync stopped | **Choose another folder…** |
| Sync is off on this Mac, PC, or computer | **Enter code…**, **Restore from a backup…**, **Start over with a new sync key…** |
| Sync needs Keychain access, Credential Manager access, or the keyring | **Try again** |
| Sval can't unlock the saved sync key on this Mac, PC, or computer | None |
| Waiting for the sync key | **Enter code…**, **Restore from a backup…** |
| Another device is using *folder* | **Enter code…**, **Dismiss** |
| Can't sync with another device | **Check for updates…** |

- **Set up folder again.** Sval makes Sval's files in the folder again.
- **Start over with a new sync key…** After you confirm, Sval makes a new
  sync key. Other devices stop syncing until you add each device again.

### Enter code

**Enter code…** opens a dialog. When Sval finds the sync key from an earlier
install in the sync folder, Sval joins with the sync key and opens no
dialog.

- The dialog says where the code comes from: on a device that is currently
  syncing to the folder, go to Settings › Sync and devices › Add a device.
- **Code.** The field takes the code in upper or lower case, with or
  without dashes.
- **Enter code.** Sval looks for the code in the sync folder until the code
  arrives. The dialog closes once this computer has the sync key.
- **Cancel.** Sval stops looking, and the dialog closes.

### Restore from a backup

**Restore from a backup…** opens a dialog with a **Backup key** field. Then
**Restore** checks the backup key against the Workspaces in the sync folder
and closes the dialog once Sval restores the sync key.

## Devices

- **Device name.** Other devices show the device name next to agent
  Workspaces. The name doesn't sync.
- **Other devices.** The names of your other devices.
- **Add a device…** The button shows while this computer is syncing. Sval
  shows a one-time code at once.

### Add a device

- The code has 12 characters in three groups. The code works for an hour,
  and a countdown shows the time left.
- **Copy.** Sval copies the code.
- **Cancel code.** The code stops working.
- When the new device joins, the page says "The new device used the code."

## Advanced › Sync key

Advanced shows while this computer is syncing.

- **Save a backup…** The Back up your sync key dialog opens with the key
  and the buttons that copy, print, or save the key. Sval offers the same
  dialog whenever Sval makes a new key.
- **Start over with a new sync key…** The same button as on the Sync card.
  Afterward, a lost device with the old sync key can't read the sync folder.
- On a computer with no keyring, a note says Sval keeps the sync key in the
  Sval profile.

## The sync indicator

Once you've chosen a sync folder, the sync indicator sits at the bottom of
the Workspace panel. Selecting the indicator opens Settings › Sync and
devices, which says the same thing in more words. The indicator says one of
these:

- How long ago Sval last synced, in minutes, hours, or days.
- **Syncing…** Sval is syncing for the first time since Sval started.
- **Not synced yet**, or **Last synced** with a time. Sval can't reach the
  sync folder.
- **Sync folder not found.** The sync folder is gone. **Choose Folder…**
  opens Settings.
- **Can't access sync folder.** Sval isn't allowed to change files in the
  sync folder. **Choose Folder…** opens Settings.
- **Sync stopped.** The files in the sync folder are too large to sync.
- **Sync is off.** The sync key on this computer is missing or doesn't match
  the sync folder's key. **Enter code…** opens the Enter code dialog in
  Settings.
- **Waiting for the sync key.** This computer has no sync key for the sync
  folder. **Enter code…** opens the Enter code dialog in Settings.
- **Another device is using the sync folder.** **Enter code…** asks for a
  code from the other device.
- **Sync needs access.** The system won't give Sval the sync key.
  **Allow Access** (**Try Again** on Windows) asks the system again.
- **A device's clock is set ahead.** The indicator names the device.
- In a private window, the indicator says tabs in private windows aren't
  saved or synced.

## When you first set up Sval

- **I'm new to Sval.** Sval sets up this computer and keeps your Workspaces
  on this computer only. On the last step, **Set up sync** opens
  Settings › Sync and devices, where you choose a folder to sync with.
- **I use Sval on another device.** Sval asks for the sync folder your other
  devices are syncing with, then for a code from a device that is syncing.
- **Restore from a backup.** On the code step, Sval takes the backup key in
  place of a code. Sval checks the backup key against the Workspaces in the
  sync folder.

## Sync

When no folder is chosen, the card reads "Sval saves your Workspaces on this
device only. To sync them, choose a folder your devices share."

- **Choose folder…** A folder picker opens. The folder you choose becomes
  this device's sync folder. Once you've chosen a folder, the button reads
  **Change…**. When Sval can't find its files in the folder, the button
  reads **Choose another…**.
- Once you've chosen a folder, its name and full path show. When the
  folder is in a cloud service Sval recognizes, like iCloud Drive, Dropbox,
  or OneDrive, Sval shows the service's name and the folder's name.
- **Show in Finder** (**Show in File Explorer** on Windows, **Show in Files**
  on Linux). The folder opens.
- **Use this folder again.** This shows while Sval can't reach the folder
  you chose. Once you've reconnected the folder, selecting this
  button tries the folder again.
- **Stop syncing.** This device stops syncing through the folder. Every
  Workspace stays on the device.
- On a Mac, a note says Sval keeps what unlocks your sync key in your Mac's
  Keychain, as "Sval secrets".
- On a computer with no keyring, a note says Sval keeps your sync key in
  your Sval profile.

Under the buttons, the sync readout says how sync is going, with the same
words as the sync indicator.

- **Sync now.** Sval syncs straight away. While Sval syncs, the readout
  says **Syncing…**. If the sync fails, the readout says
  **Couldn't sync**.
- The readout has the same buttons as the sync indicator, listed below.

## Your devices

- **This device's name.** Your other devices show this name next to
  agent Workspaces from this device. The name doesn't sync.
- **Sync with another device.** The steps for adding a device open. This
  button shows once you've chosen a sync folder. Until then, the card says
  **Choose a sync folder first.** and offers **Go to Sync**.

## Sync with another device

- **This device shows a code.** This device gives its key to another
  device.
- **The other device shows a code.** This device takes the key from
  another device.
- **Back.** You go to the step before. The button is hidden while a code
  shows or Sval is looking for a code.

### This device shows a code

- The first step names the sync folder, which the other device needs too.
- **Show code.** Sval makes a one-time code of 12 characters in three
  groups. The code works for an hour. A countdown shows the time left.
- **Copy.** Sval copies the code.
- **Cancel code.** The code stops working.
- When the other device joins, the page reads **Code used. Your devices are
  syncing.**

### The other device shows a code

- The first step names the sync folder, which both devices need.
- **Next.** You go to the code step. If Sval finds your sync key in the
  folder, left from an earlier install on this computer, Sval joins with
  that key and asks for no code.
- **Type the code it shows.** This field takes the code in upper or lower
  case, with or without dashes.
- **Join.** Sval looks for the code in the sync folder, and keeps looking
  until the code arrives.
- **Stop.** Sval stops looking.

## Advanced › Sync key

Advanced shows once a sync folder is chosen.

- **Save a backup.** The Back up your sync key dialog opens. It shows the
  key, with **Copy**, **Print…**, and **Save to a file…**. Sval offers the
  same dialog when it makes a new key. Until you copy, print, or save the
  key, the page says **You haven't saved a backup.**
- **Set up sync again.** After you confirm, Sval makes a new sync key. Your
  other devices stop syncing until you give each one a new code. The old
  key can't read the folder anymore.
- **Restore from a backup.** This field takes a key you backed up. **Restore** checks
  the key against the Workspaces in the sync folder, then uses it.

**Save a backup** and **Set up sync again** show only on a device that
syncs.

## The sync indicator

Once you've chosen a sync folder, the sync indicator sits at the bottom of
the Workspace panel. Selecting the indicator opens Settings › Sync and devices. The
indicator says one of these:

- How long ago Sval last synced, in minutes, hours, or days.
- **Syncing…** Sval is syncing for the first time since it started.
- **Not synced yet**, or **Last synced** with a time. Sval can't reach your
  sync folder.
- **Sync folder not found.** The folder is gone. **Choose Folder…** chooses
  another one.
- **Can't access sync folder.** Sval isn't allowed to change files in the
  folder. **Choose Folder…** chooses another one.
- **Sync stopped.** The files in the folder are too large to sync.
- **Sync is off.** This device's sync key is missing or doesn't match the
  folder's key. **Reconnect…** asks for a code from another device.
- **Pair your other device.** The folder has Workspaces from a device that
  isn't syncing with this one. **Enter Code…** asks for that device's code.
- **Sync needs access.** The system won't give Sval the sync key.
  **Allow Access** (**Try Again** on Windows) asks the system again.
- **Update Sval.** Another device runs a newer Sval. **Update** looks for
  the update.
- In a private window, the indicator says the window's tabs aren't saved or
  synced.

## When you first set up Sval

- **I'm new to Sval.** Sval sets up this device, and saves your Workspaces
  on this device only. On the last step, **Set up sync** opens
  Settings › Sync and devices, where you choose a folder to sync through.
- **I use Sval on another device.** This device joins a device that already
  syncs. Sval asks for the folder that device uses. Then Sval asks for the
  code that device shows.
- **Restore with your backup key.** This shows on the code step. It takes
  your backed-up key in place of a code. Sval checks the key against the
  Workspaces in the folder, then uses it.
