In this tutorial you set up Sval on a first computer, sync it through a
cloud folder, and then set up a second computer with the same Workspaces.
It takes about 15 minutes, and you spend most of that time waiting for the
cloud folder.

## Before you start

- Install Sval on both computers, but don't open it on the second one yet.
- Pick a cloud folder both computers reach, like iCloud Drive, Dropbox, or
  OneDrive. Make sure the cloud service's app is set up and signed in on
  both computers. This tutorial uses a folder called Sval in iCloud Drive.

## Set up the first computer

1. Open Sval. The Welcome to Sval dialog opens.
2. On each page of the introduction, select **Next**.
3. On the last page, select **Get started**.
4. On Is this your first time using Sval?, select **I'm new to Sval**, then
   **Continue**.
5. On each of the next steps, make a choice and select **Continue**.
6. On the last step, select **Set up sync**. Settings › Sync and devices
   opens.
7. Select **Choose folder…**, then choose the Sval folder in your cloud
   folder. The card reads "iCloud Drive › Sval".

On a Mac, macOS asks whether Sval can use "Sval secrets". Choose
**Always Allow** each time macOS asks, on both computers.

## Save your sync key

When you've chosen the folder, Sval shows Back up your sync key.

1. Select **Copy**.
2. Paste the key into a secure note in your password manager.
3. Select **Done**.

## Show a code on the first computer

1. Open Settings › Sync and devices.
2. Under Your devices, select **Sync with another device**.
3. Select **This device shows a code**.
4. Select **Show code**.

The page shows a code like K7Q4-8MTZ-3RJW. Leave this page open.

## Set up the second computer

1. Open Sval. The Welcome to Sval dialog opens.
2. In the introduction, select **Skip**.
3. On Is this your first time using Sval?, select **I use Sval on another
   device**, then **Continue**.
4. Select **Choose folder…**.
5. Choose the same Sval folder in your cloud folder.
6. Select **Continue**.
7. In **Code**, type the code the first computer shows.
8. Select **Continue**.

The step reads "Waiting for iCloud Drive to sync from your other device…".
After a few minutes, it reads "Your tabs and settings are here." On the
first computer, the page reads "Code used. Your devices are syncing."

## Finish the second computer

1. Select **Continue**.
2. On Your search engine, keep the engine your first computer uses and
   select **Continue**.
3. On each of the next steps, make a choice and select **Continue**.
4. On the last step, select **Start browsing**.

Sval shows the Workspaces and tabs from your first computer.

## Try it

1. On the first computer, open a new tab and go to codeberg.org.
2. On the second computer, look at the tabs in the Workspace.

Once the cloud folder has carried the change, the Codeberg tab shows in the
Workspace on the second computer too.
