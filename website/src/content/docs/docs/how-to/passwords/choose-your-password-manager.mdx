Sval doesn't save passwords. Instead, you choose the password manager you
already use. Sval then installs that password manager's extension from
addons.mozilla.org.

You keep your passwords in Bitwarden, and you want Bitwarden to fill in your
sign-ins in Sval.

<Screenshot name="docs-password-manager" frame="rounded" maxWidth={600} alt="Settings › Privacy and protection › Password manager, with a button for each password manager and None of these selected" />

## Steps

1. Open Settings › Privacy and protection.
2. Under Password manager, select your password manager.
3. Select **Add extension**.

While the extension installs, Sval shows **Adding its extension…**, then
**Saved.** The
extension appears in the extensions menu. Sign in to your password manager
there.

## Details

- Sval offers 1Password, Bitwarden, Dashlane, iCloud Passwords, KeePassXC,
  LastPass, NordPass, and Proton Pass. iCloud Passwords is offered on macOS
  and Windows only.
- When you first set up Sval, it asks "Which password manager do you
  use?". Choosing there does the same thing as choosing in Settings later.
- If you choose **None of these**, Sval installs nothing, and the button
  reads **Save**. Switching to None of these doesn't remove an extension
  you already have. To remove the extension, see
  [Remove an extension](/docs/how-to/extensions/remove-an-extension/).
- If you removed your password manager's extension, choose the password
  manager again to reinstall the extension.
- Your choice stays on this device. Make the choice on each of your
  devices.
- Sval never offers to save a password, and has no list of saved passwords
  of its own.

## If something goes wrong

- **Couldn't install it. Sval tries again the next time it starts.** The
  extension didn't download. Sval keeps your choice. Sval tries again the
  next time it starts, and when your connection comes back. Meanwhile, the
  extensions button shows a notice, such as "Bitwarden couldn't be
  installed: you're offline." To try again right away, select **Try Again**
  in the notice.
- **Couldn't change the password manager.** Sval didn't save your choice.
  Select the button again.
