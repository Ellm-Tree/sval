---
title: Manage a security key
description: Set a hardware security key's PIN, see its passkeys, and add fingerprints, on macOS and Linux.
---

Sites can sign you in with a passkey or a hardware security key. On macOS
and Linux, Sval has a page for managing the security keys you plug in.

You've bought a new security key and want to give it a PIN before you add
it to your Fastmail account.

## Steps

1. Plug in the security key.
2. Open Settings › Privacy and protection.
3. Under Security keys, select **Manage security keys**.

The security key manager opens in a new tab. There you can set or change
the key's PIN, and see and remove the passkeys on the key. If the key reads
fingerprints, you can add fingerprints too.

## Details

- The Security keys card isn't in Settings on Windows.
- Signing in with a passkey or a security key works on every platform. The
  site asks for your passkey or key, and you follow the site's steps.
