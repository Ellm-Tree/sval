---
title: Install an extension update now
description: Skip the wait on an extension update Sval is holding.
---

When Sval finds an extension update, it waits 7 days before installing it. An
extension can change hands, or start doing harm through an update. The wait
gives Mozilla time to find a harmful update and turn it off before it
reaches you. If you don't want to wait, you can install the update now.

Sval is holding an extension update with a fix you've been waiting for.

## Steps

1. Open Settings › Extensions.
2. Under Installed, select the extension's name.
3. In the Update waiting row, select **Update now**.

If the update asks for new permissions, Sval asks you first.

## Details

- The Update waiting row shows the new version, and the date Sval installs
  the update by itself.
- The wait counts from the day this device first found the update.

## If something goes wrong

- **Sval couldn't install the update. Try again later.** The update didn't
  download or install. Select **Update now** again later.
