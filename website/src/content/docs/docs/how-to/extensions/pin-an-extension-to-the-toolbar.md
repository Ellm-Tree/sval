---
title: Pin an extension to the toolbar
description: Put an extension's button on the toolbar, or take it off again.
---

When an extension has a button, you'll find the button in the extensions
menu. Pin the extension to put its button on the toolbar as well.

You use your password manager's button many times a day and want it one
click away.

## Steps

1. In the toolbar, select **Extensions**.
2. On the extension's row, select **Pin to the toolbar**.

The extension's button appears on the toolbar, next to the extensions
button.

## Details

- A pinned extension stays listed in the extensions menu. To unpin the
  extension, select **Unpin from the toolbar** on its row.
- You can pin only an extension that has a button.
- When you install an extension, the extensions menu tells you it was
  added and offers **Pin to toolbar**.
