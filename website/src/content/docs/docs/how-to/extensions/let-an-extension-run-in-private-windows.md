---
title: Let an extension run in private windows
description: Allow an extension to work in private windows, or stop it.
---

An extension doesn't run in private windows until you let it. Once it
runs in a private window, the extension can see what you do there.

You want your password manager to fill in sign-ins in private windows too.

## Steps

1. Open Settings › Extensions.
2. Under Installed, select the extension's name.
3. Under Extension, turn on **Run in private windows**.

The extension restarts so the change takes effect.

## Details

- Some extensions can't run in private windows. Their page shows **Never**.
- Some extensions need private windows to work. Their page shows
  **Always**. You can't change the setting for those extensions.
