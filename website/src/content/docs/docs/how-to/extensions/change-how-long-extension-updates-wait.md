---
title: Change how long extension updates wait
description: Set how many days Sval holds an extension update before installing it.
---

When Sval finds an extension update, it waits a number of days before
installing the update. The wait gives Mozilla time to find a harmful update
and turn it off before it reaches you.

You'd rather have extension updates as soon as they're out.

## Steps

1. Open Settings › Extensions.
2. In **Days to wait before installing extension updates**, type a number of days.

## Details

- The wait is 7 days until you change it. Type 0 to install updates right
  away. The longest wait is 365 days.
- If you leave the field empty, or type something that isn't a number of
  days, the wait goes back to 7.
- Your other devices use the same number.
- When Sval is holding an update, the extension's page shows the update.
  To install the update at once, select **Update now** there. See
  [Install an extension update now](/docs/how-to/extensions/install-an-extension-update-now/).
