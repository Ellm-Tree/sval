---
title: Load a blocked embed
description: Let an Instagram, TikTok, X, or Disqus embed load on a page where blocking replaced it.
---

When blocking stops an Instagram, TikTok, X, or Disqus embed, the page shows
a placeholder instead. The embed loads only if you allow it.

A blog post embeds an Instagram photo you want to see.

## Steps

1. On the placeholder, select the button.
2. Sval asks whether to allow the embed on the site. Choose **Allow**.

The embed loads in the page.

## Details

- **Not now.** The placeholder stays as it is.
- When you allow the embed, that company's content loads on the page, and
  so do its trackers.
