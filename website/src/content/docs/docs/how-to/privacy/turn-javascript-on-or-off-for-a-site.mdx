To turn JavaScript on or off for the site you're on, use the JavaScript
button in the address bar. To turn JavaScript off for every site, use
Settings › Sites.

A recipe site fills the page with pop-ups while you read, and the site works
fine without JavaScript.

<Screenshot name="home-site-controls-v2" alt="Site settings for bonappetit.com: zoom, element removal, Colorshift, video and audio, JavaScript, and per-site permissions" />

## Steps

1. In the address bar, select the JavaScript button.

The tab reloads, with JavaScript switched the other way for that site. The
button's tooltip says whether JavaScript is on, and whether your rule set
it.

## Turn it off for every site

1. Open Settings › Sites.
2. Under Defaults, turn off **Run JavaScript on every site**.

Sites you allowed with the JavaScript button still run JavaScript.

## Details

- The JavaScript button shows in the address bar unless you unpin it. The
  site settings menu has the same switch, under JavaScript. To put the
  button back in the address bar, select the pin next to that switch.
- With JavaScript off, most sites lose menus, video players, and sign-in.
- Your choice syncs to your other devices.
- On an address like `nas.example.com`, the button changes that address
  alone. To cover all of `example.com`, open the site settings menu and pick
  All of example.com in the menu's title.
- You can't change a site's JavaScript in a private window, because the
  choice is saved and synced.
- To put a site back on the default, open the site's page in Settings ›
  Sites. Under JavaScript, choose **Default**.
