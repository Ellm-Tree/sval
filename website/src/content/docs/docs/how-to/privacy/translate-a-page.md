---
title: Translate a page
description: Translate a page in another language into yours, on your device.
---

When a page is in a language other than yours, a Translate button shows next
to the site controls. Sval translates the page on your device.

You open a Codeberg project whose README is in German.

## Steps

1. In the address bar, select the Translate button next to the site
   controls.
2. Select **Translate**.

While the page is translated, the button shows your language's code.

## Details

- To go back to the page's own language, select the button again, then
  select **Show original**.
- Translation runs on your device. Sval downloads the translation models it
  needs from Mozilla's Remote Settings. The page's text never leaves your
  computer to be translated.
- The Translate button shows only while the page can be translated into
  your language, or while the page is translated.
