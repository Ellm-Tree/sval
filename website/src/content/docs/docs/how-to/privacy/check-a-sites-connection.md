---
title: Check a site's connection and certificate
description: See whether a site's connection is secure, who its certificate says runs it, and when it expires.
---

You can check a site's connection and certificate from the Privacy and
Security button in the address bar. The button warns you when a connection
isn't secure.

You're about to type a card number and want to know the page is encrypted
and run by the shop.

## Steps

1. In the address bar, select the Privacy and Security button.
2. Select the connection line under the site's name.

The connection line reads something like Connection secure. The
Privacy and Security panel then shows who the certificate is verified as,
and who issued the certificate. It also shows when the certificate is
valid, and the encryption the connection uses.

## Details

- **More information.** Page Info opens for the site.
- When a connection isn't secure, the button itself shows **Not secure**,
  and the Privacy and Security panel opens with a warning.
- **HTTPS-Only on this site.** This switch shows when HTTPS-Only Mode is on
  and you've made an exception for the site. Turn the switch on, and Sval
  tries HTTPS first and reloads the tab.
- If you trusted a site's certificate yourself, select **Remove certificate
  exception** to take that trust back. Sval then warns you again and stops
  loading the site.
- To return to the first view, select **Back**.
