---
title: Search the web
description: Search with your default engine from the Launcher, the address bar, or the home page.
---

When you type something that isn't an address, Sval searches for it with
your default search engine. The Launcher, the address bar, and the home page's search
field all work the same way.

You want to look up a recipe while you're on another page.

## Steps

1. Press <kbd>⌘L</kbd> (<kbd>Ctrl+L</kbd> on Windows and Linux).
2. Type what you're looking for.
3. Press Enter.

The results open in the tab you're on.

## Details

- To open the results in a new tab, press <kbd>Shift+Enter</kbd>. To open
  them in a new window, press <kbd>⇧⌘Enter</kbd> (<kbd>Ctrl+Shift+Enter</kbd>).
  To open them next to this tab in a Split, press <kbd>⌥Enter</kbd> (<kbd>Alt+Enter</kbd>).
- As you type, your search engine suggests searches under Search
  suggestions. Select one to search for it.
- To remove a past search from the list, select it, then press
  <kbd>⇧⌫</kbd> (<kbd>Shift+Delete</kbd> on Windows and Linux).
- On the home page, you can type in the search field instead. The field
  lists the same rows as the Launcher.
- When what you type closely matches an open tab, the tab is the first
  row and the search comes right after it. Press the Down arrow to reach
  the search.
