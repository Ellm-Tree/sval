---
title: Search with a keyword
description: Type a keyword before your search, like @yt for YouTube or @gh for GitHub, to search with that engine.
---

Every search engine Sval comes with has a short keyword that starts with
`@`. When you type the keyword and a space before your search, Sval
searches with that engine.

You want to find a cat video on YouTube without opening YouTube first.

## Steps

1. Press <kbd>⌘L</kbd> (<kbd>Ctrl+L</kbd> on Windows and Linux). The
   Launcher opens.
2. Type `@yt` and a space. YouTube's name shows at the start of the field.
3. Type `cats`.
4. Press Enter.

YouTube's results for cats open in the tab you're on.

## Details

- The keywords Sval comes with:

  | Keyword | Searches |
  |---|---|
  | `@yt` | YouTube |
  | `@gh` | GitHub |
  | `@w` | Wikipedia, in your language |
  | `@maps` | OpenStreetMap |
  | `@ddg` | DuckDuckGo |
  | `@sp` | Startpage |
  | `@br` | Brave Search |
  | `@kagi` | Kagi |
  | `@g` | Google |
  | `@b` | Bing |
  | `@eco` | Ecosia |
  | `@qw` | Qwant |
  | `@pplx` | Perplexity |

- You can type the keyword and your search in one go, like `@gh sval`.
- Type `@` alone to see every engine with its keyword.
- You can type the start of a keyword, then press <kbd>Space</kbd> or
  <kbd>Tab</kbd>. Sval picks the first engine whose keyword starts with
  what you typed, so `@k` picks Kagi. A whole keyword always picks its own
  engine, so `@b` is Bing and `@br` is Brave Search.
- To search with your default engine again, press <kbd>⌫</kbd>
  (<kbd>Backspace</kbd>) in the empty field.
- Keywords work the same way in the address bar and in the search field
  on the home page.
- Sval sends your search to YouTube, GitHub, or OpenStreetMap only when
  you press Enter. Sval doesn't ask those sites for suggestions as you type.
- Every engine except Kagi also has a longer keyword, like `@youtube` and
  `@google`.
- To skip the `@`, [set your own keyword](/docs/how-to/search/set-your-own-search-keyword/)
  for the engine.
