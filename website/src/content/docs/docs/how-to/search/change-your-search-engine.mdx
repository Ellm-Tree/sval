Your default search engine is the one Sval uses when you type something
that isn't an address. You picked it when you first set up Sval, and you
can change it whenever you like.

You've been using DuckDuckGo and want to try Startpage for a week.

<Screenshot name="docs-default-engine" frame="rounded" maxWidth={600} alt="Settings › Search and Launcher › Default search engine, set to DuckDuckGo" />

## Steps

1. Open Settings › Search and Launcher.
2. Under Default search engine, choose an engine from the menu.

Your next search uses the new engine.

## Details

- DuckDuckGo is the default until you choose another.
- The menu lists DuckDuckGo, Startpage, Brave Search, Kagi, Google, Bing,
  Ecosia, Qwant, Perplexity, and Wikipedia. It also lists any engine you've
  added.
- Your choice syncs to your other devices.
- The address bar, the Launcher, and the home page's search field all
  search with the same engine.
- To search once with another engine, type its keyword and a space before
  your search. Settings › Search and Launcher lists each engine's keyword
  under Additional search engines.
- If you choose Kagi, sign in to Kagi as well. See
  [Sign in to Kagi](/docs/how-to/search/sign-in-to-kagi/).
