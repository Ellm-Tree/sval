---
title: Set your own keyword for a search engine
description: Give a search engine a keyword of your own, like yt, to search it without typing @.
---

Every search engine Sval comes with has a keyword that starts with `@`. You
can give an engine a keyword of your own too. Your keyword doesn't need an
`@`.

You search YouTube often and want to type `yt` instead of `@yt`.

## Steps

1. Open Settings › Search and Launcher.
2. Under Additional search engines, find the engine. Its keywords show
   under its name.
3. On the engine's row, select **Edit search engine**, the pencil button.
4. In **Keyword (optional)**, type your keyword, like `yt`.
5. Select **Save Engine**.

Your keyword works at once in the Launcher, the address bar, and the home
page's search field. The engine's `@` keywords keep working too.

## Details

- A keyword works only at the start of what you type. A keyword without an
  `@`, like `yt`, picks its engine whenever a search starts with that
  keyword and a space. Choose one you don't start ordinary searches with.
- To remove your keyword, clear the **Keyword (optional)** field and select
  **Save Engine**.

## If something goes wrong

- **That keyword is already being used. Try a different one.** Another
  engine has that keyword. Choose another keyword.
