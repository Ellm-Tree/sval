A Workspace's name, color, and emoji show above your tabs and in the
window's title. The color also tints the window and the home page.

Your Work and Home Workspaces are both blue, and you want to tell them apart
at a glance.

<Screenshot name="docs-edit-workspace" frame="rounded" maxWidth={460} alt="The Edit Workspace dialog for Ceramics Shop, with its name, a vase emoji, the color Pink, and Archive idle tabs set to Use Default (Never)" />

## Steps

1. Above your tabs, right-click the Workspace's name.
2. Choose **Edit…**.
3. Change the **Name**, the **Emoji**, or the **Color**.
4. Select **Save**.

## Details

- To edit a Workspace the window isn't showing, open the Workspaces list
  and right-click that Workspace there.
- To remove the emoji, select **Emoji**, then choose **No emoji**.
- To remove the Workspace's color, choose **Sval Default**.
- The changes sync to your other devices.

## If something goes wrong

- **Couldn't save the color or emoji.** The dialog stays open with your
  choices. Select **Save** to try again. A new name you typed is already
  saved.
