When Archive idle tabs puts a tab away, Sval keeps the tab in History,
under Archived tabs. Select the tab there to put it back in its Workspace.

You remember reading a Roon support page last week, and the tab is gone
from your Home Workspace.

## Steps

1. In the toolbar, select **History**.
2. In the History sidebar, select **View**.
3. Choose **Archived tabs**.
4. Optional: type part of the page's title or address in the search box.
5. Select the tab's row.

The tab opens in the Workspace it came from, between the same tabs as
before. If a window shows that Workspace, the tab opens there. If not, the
window you're in switches to that Workspace.

<Screenshot name="docs-archived-tabs" alt="The History sidebar on Archived tabs: The Verge from Work, and Portugal – Wikipedia and CNN Travel from Home, each with when it was archived" />

## Details

- The list shows the newest tabs first. Each row shows the page, the
  Workspace the tab came from, and when Sval archived the tab.
- A tab you've put back stays in the list, dimmed, until the tab expires.
  If you select the tab again, Sval opens another copy.
- If the tabs on either side of it are gone, the tab goes at the end of its
  Workspace. If its Workspace is gone, the tab goes at the end of the
  Workspace you're in.
- A Split comes back whole, whichever tab in the Split you select.
- The list is the same on all your devices. A tab archived on one device
  can be put back on another.
- In the menu bar, choose **History › Archive** to open the same list.
- A private window has no archived tabs.
