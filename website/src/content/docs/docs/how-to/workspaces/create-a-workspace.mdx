A Workspace holds its own tabs and groups. Each window shows one Workspace,
and the Workspace's color tints the window and the home page.

You're starting a project and want to keep the project's tabs apart from
your everyday tabs, so you make a Workspace called Work.

<Screenshot name="docs-create-a-workspace" frame="rounded" maxWidth={560} alt="The New Workspace dialog: the name Ceramics Shop, a noodle emoji, the color Orange, dark, Transparency at 0%, and Isolate this Workspace unchecked" />

## Steps

1. Above your tabs, select the current Workspace's name.
2. At the bottom of the list, choose **New Workspace…**.
3. In **Name**, type a name for the Workspace.
4. Optional: select **Emoji**, then choose another emoji.
5. Optional: under **Color**, select a color.
6. Select **Create**.

The window goes to the new Workspace, which starts empty.

## Details

- Sval gives a new Workspace a random emoji. To remove the emoji, select
  **Emoji**, then choose **No emoji**.
- A new Workspace has **No color** until you pick one.
- To give the Workspace its own cookies and sign-ins, check **Isolate this
  Workspace** before you select **Create**. See
  [Isolate a Workspace](/docs/how-to/workspaces/isolate-a-workspace/).
- Your Workspaces sync to your other devices, along with their tabs and
  groups.
- You can also make a Workspace while moving a tab. See
  [Move a tab to another Workspace](/docs/how-to/workspaces/move-a-tab-to-another-workspace/).
- New Workspace has no keyboard shortcut until you give it one in
  Settings › Keyboard shortcuts.

## If something goes wrong

- **Name can’t be empty.** A Workspace needs a name. Type one, then select
  **Create** again.
