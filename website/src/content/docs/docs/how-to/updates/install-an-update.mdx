Sval downloads updates by itself. When an update is ready, a message opens under
the **Notices** button in the header, asking you to restart.

An update is ready while you're in the middle of something. You want to
finish first, then restart.

## Restart to update

1. In the header, select **Notices**.
2. Select **Update and restart**.

Sval restarts on the new version and brings back your tabs and windows.

## Check for an update yourself

1. Open Settings.
2. In the list on the left, select About Sval.
3. Under the updates heading, select **Check for updates**.

If Sval finds an update, it downloads it. After that, the same
button restarts Sval to finish.

## Details

- The message stays open until you select the Notices button or one of the
  message's buttons. It doesn't open again by itself for that update.
- **Dismiss.** The message closes. The Notices button stays in the header
  until you restart, and shows one row saying the update is available.
  Selecting the row restarts Sval.
- When Sval is set to let you choose when to install, the message offers
  **Download** in place of Update and restart.
- Some messages have a **Learn more** link to the release notes.

## If something goes wrong

<Until v="0.1.0-rc.10">

- **Close the other copy of Sval to finish updating.** Another copy of
  Sval is running from the same place. Quit the other copy, or
  select **Update Anyway**. If you update anyway, the other copy might not
  work as it should until you restart it.

</Until>
<Since v="0.1.0-rc.10">

- **Close the other copy of Sval to finish updating.** Another copy of
  Sval is running from the same place. Quit the other copy, and within 10
  seconds the message changes to the usual one, with **Update and
  restart**. You can also select **Update and Restart Anyway**. If you
  update anyway, the other copy might not work as it should until you
  restart it.

</Since>
- **Sval couldn't update automatically.** Select **Download**, then
  install the new version yourself. You don't lose your saved information
  or settings.
