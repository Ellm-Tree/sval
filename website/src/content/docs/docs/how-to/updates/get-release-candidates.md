---
title: Get release candidates
description: Try each Sval release before it ships.
---

A release candidate is a version of Sval that's ready to ship. It goes
first to people who want to try it. When you turn on release candidates,
Sval updates to each candidate as well as to each regular release.

You want to try new features a few days early and report what breaks.

## Steps

1. Open Settings.
2. In the list on the left, select About Sval.
3. Under Release candidates, turn on **Receive release candidate updates**.

Sval checks for candidates from then on.

## Details

- Regular releases arrive either way.
- When you turn the setting off, Sval waits for the next regular release
  that's newer than the version you have. Sval never goes back to an older
  version.
- If you installed Sval from a release candidate, the setting starts
  turned on.
- You'll see Release candidates only on a copy of Sval that updates
  itself.
