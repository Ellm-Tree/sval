---
title: See downloads from every Workspace
description: Switch the Downloads list from the Workspace you're in to every Workspace, and remove downloads from the list.
---

The Downloads list shows the files you downloaded in the Workspace you're
in. You can switch the list to show downloads from every Workspace.

You downloaded an invoice from Fastmail in Home, and you're in Work now.

## Steps

1. In the toolbar, select **Downloads**.
2. At the top of the list, select **All Workspaces**.

Each download now shows the Workspace it came from.

## Remove downloads from the list

- To remove one download, select **Remove from list** next to it.
- To remove every finished download the list shows, select **Clear list**
  at the bottom.

Removing a download from the list leaves the file on your computer.

## Details

- When the Workspace you're in has no downloads but other Workspaces do,
  the list offers **Show all Workspaces**.
- Clear list removes only the downloads the list shows. With This Workspace
  chosen, downloads from other Workspaces stay.
- In a private window, the list shows only the downloads started in that
  window.
