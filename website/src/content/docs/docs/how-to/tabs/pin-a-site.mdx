A pin keeps a site as an icon in the row at the top of the Workspace
panel. The pin's page stays where you left it while you work in other
tabs. You can take the pin back to its saved page at any time.

You keep Fastmail open all day. You want it one click away, and you want
links in your mail to leave your inbox where it is.

<Screenshot name="docs-pin-a-site" frame="rounded" maxWidth={300} alt="The pins row with Fastmail selected and showing its name, next to Roon, Codeberg, Linear, and Figma" />

## Pin the tab you're on

1. In the Workspace, right-click the tab, then choose **Pin**.

The tab leaves the list of tabs and becomes a pin at the end of the row.
The page stays as it was.

To pin the tab only in the Workspace you're in, choose
**Pin to This Workspace** in place of Pin.

## Pin by dragging

1. Drag the tab's row up to the pins row.
2. Drop it where you want the pin among the others.

When you have no pins yet, the space under the Favorites button reads
**Drop to pin** while you drag.

## Keep pins in a folder

1. In the pins row, drag a pin onto the middle of another pin.
2. In the Create Pin Folder dialog, type a name for the pin folder.
3. Select **Create**.

The pin folder holds both pins, and it shows in the pins row as one tile.
If you leave the name as it is, the pin folder is named "Untitled pin
folder". If you cancel the dialog, Sval makes no pin folder, and both pins
stay where they were. Selecting the tile opens the pin folder's pins. Dropping a pin on
the edge of another pin moves the dropped pin to that spot and makes no pin
folder.

- To put another pin in the pin folder, drag the pin onto the middle of the
  pin folder's tile. You can also right-click the pin, choose
  **Move to Pin Folder**, then choose the pin folder.
- To take a pin out, select the pin folder's tile, then drag the pin onto
  the pins row.
- To make an empty pin folder, right-click the pins row next to the pins,
  then choose **New Pin Folder…**. The pin folder goes at the end of the
  row.

<Since v="0.1.0-rc.11">

- To change the order of the pins in a pin folder, select the pin folder's
  tile, then drag a pin to a new spot.

</Since>

When you move a pin out of a pin folder and one pin or none is left, Sval
removes the pin folder. If one pin is left, that pin takes the pin folder's
place in the row.

## Go back to the saved page

1. In the pins row, point to the selected pin.
2. Select the refresh button at the end of the pin, named "Back to" and the pin's name.

The refresh button shows only while the pin is away from its saved page.
You can also right-click the pin and choose **Back to saved page**.

## Details

- When you select a pin, its page is where you left it. Selecting a pin
  never reloads the saved page by itself.
- A link to a page on another site opens in a Quick Peek over the pin, so the pin
  stays on its own site. Both app.fastmail.com and www.fastmail.com are on
  fastmail.com, so a link from one to the other stays in the pin. <kbd>⌘</kbd>-click (Ctrl-click on Windows and Linux) opens
  the link in a new tab. You can turn off **Open links to other sites from a
  pin in a Quick Peek** in Settings › Links › Links in pages.
- Closing a selected pin, for example with <kbd>⌘W</kbd> (<kbd>Ctrl+W</kbd> on Windows and
  Linux), takes the pin back to its saved page. The icon stays.
- After a restart, each pin starts at its saved page.
- To have a pin go back to the page it shows now, right-click the pin and
  choose **Save current page as this pin**.
- Each Workspace has its own page for a pin. That page uses the
  Workspace's sign-ins. In an isolated Workspace, you can be signed in to
  another account on the same pin.
- If a pin was the last thing you looked at in a Workspace, Sval shows the
  pin when you come back to that Workspace or restart.
- <kbd>⌘1</kbd> to <kbd>⌘9</kbd> (<kbd>Ctrl+1</kbd> to <kbd>Ctrl+9</kbd> on Windows, <kbd>Alt+1</kbd> to <kbd>Alt+9</kbd> on Linux) select
  the first nine pins. Hold <kbd>⌘</kbd> to see their numbers.

- Pins sync to your other devices. You can rename a pin, and export it with
  your Favorites. Pinning a tab doesn't add its page to Favorites.

- You can pin only a web page or a file. You can't pin a tab in a Split
  until you separate the Split.
- Private windows and agent Workspaces show no pins.
- The pins row shows four lines of pins. Past that, the last icon reads "+"
  and the number of pins it holds. You can change the number of lines in
  Settings › Workspaces › Pins.
