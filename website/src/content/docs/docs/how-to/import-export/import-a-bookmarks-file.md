---
title: Import a bookmarks file
description: Import bookmarks from an HTML file any browser exports, or the export file Arc makes.
---

Every browser can export its bookmarks as an HTML file, and Sval can import
that file. Sval also reads the file Arc makes when you export your
data, so you can bring your Spaces over without Arc installed.

You've moved from a browser Sval can't read, or you've removed Arc but
kept the file Arc exported.

## Steps

1. Open Settings › Workspaces.
2. Under Import and export, select **Import data**.
3. Select **Import a bookmarks file…**.
4. Choose the HTML file, or Arc's `Arc Data Export.md`.
5. Optional: under the file's row, choose where the file's bookmarks go.
6. Select **Import**.
7. When the import finishes, select **Done**.

## Details

- Once you choose the file, its row is checked and open. The browser you
  used last is checked too. To import only the file, uncheck that browser.
- To get a bookmarks file, open your other browser's bookmarks manager and
  choose Export.
- Bookmarks from an HTML file go **Into Favorites**. You can put them in a
  Workspace of their own instead, or choose **Don't import**.
- From Arc's export file, each Space arrives as a Workspace with its
  folders and tabs. The file has no tab titles, colors, emoji, or Splits, so
  none of those come over.
- When the import page can't read a browser, that browser's result line
  offers **Import Bookmarks File…**. Select it to import a file straight
  into Favorites.

## If something goes wrong

- **Couldn't read this file.** The file isn't a bookmarks file Sval can
  read. Export the bookmarks again as HTML.
