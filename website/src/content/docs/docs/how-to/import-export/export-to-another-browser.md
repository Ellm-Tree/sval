---
title: Export to another browser
description: Save your Workspaces and Favorites as a file the browser you're moving to can import.
---

Sval can save your Workspaces and Favorites as a file that your next
browser can import. Each Workspace becomes a folder of bookmarks. Your
Favorites go to the new browser's favorites bar.

You're trying out another browser for a while and want your Work Workspace
there too.

## Steps

1. Open Settings › Workspaces.
2. Under Import and export, select **Export data**.
3. Under The browser you're moving to, choose the browser.
4. Under What to export, uncheck any Workspace you want to leave out.
5. Select **Export…**.
6. Choose where to save the file, then save it.
7. Read the steps Sval shows for the other browser, then select **Done**.

## Details

- You can export for Chrome, Edge, Brave, Vivaldi, Opera, Arc, Dia,
  Firefox, Zen, or Safari. Choose **Another browser** to get a bookmarks
  HTML file that most browsers can import.
- Once the file is saved, Sval tells you where to import the file in the
  other browser. Sval also tells you how to turn a folder back into a tab
  group or Workspace there.
- For Arc and Dia, Sval tells you to import the file into Chrome first, then
  import from Chrome in Arc or Dia.
- For Safari, the list also has **History**, which exports your history.
- Every Workspace, **Favorites**, and **History** are checked to start
  with.
- You can also open this dialog by right-clicking a favorite and choosing
  **Export…**.
- To save everything Sval holds, see
  [Export all your Sval data](/docs/how-to/import-export/export-all-your-data/).

## If something goes wrong

- **Couldn't save the file. Try another place.** Select **Export…** again
  and choose another folder.
