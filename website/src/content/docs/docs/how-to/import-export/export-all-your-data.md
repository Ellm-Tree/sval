---
title: Export all your Sval data
description: Save everything Sval keeps on this device as one plain JSON file.
---

Sval can save your Workspaces, Favorites, history, and settings from this
device in one file. You can read the file without Sval.

You want a copy of everything Sval holds, to keep or to read with your own
tools.

## Steps

1. Open Settings › Workspaces.
2. Under Import and export, select **Export all Sval data**.
3. Select **Export…**.
4. Choose where to save the file, then save it.
5. Select **Done**.

## Details

- The file is a ZIP named "Sval data" followed by the date. Inside is
  plain JSON, with a README that describes the contents.
- The file isn't encrypted, and it doesn't include any key. Keep it somewhere
  only you can reach.
- The file holds what Sval keeps on this device.
- **Sval (complete data)** in the export dialog does the same thing.
  You'll find it at the end of the list under The browser you're moving to.

## If something goes wrong

- **Couldn't save the file. Try another place.** Select **Export…** again
  and choose another folder.
