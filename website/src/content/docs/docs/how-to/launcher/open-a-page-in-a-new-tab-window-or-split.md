---
title: Open a page in a new tab, window, or Split
description: Choose where a page you type or pick in the Launcher opens, with the key you press.
---

When you pick something in the Launcher, Enter opens it in the tab you're
on. To open it somewhere else, hold another key as you press Enter.

You're writing in Fastmail and want to look something up without leaving
the message.

## Steps

1. Press <kbd>⌘L</kbd> (<kbd>Ctrl+L</kbd> on Windows and Linux).
2. Type an address or a search, or move to a row with the arrow keys.
3. Press the keys for where you want the page to open:
   - Enter opens it in this tab.
   - <kbd>Shift+Enter</kbd> opens it in a new tab.
   - <kbd>⇧⌘Enter</kbd> (<kbd>Ctrl+Shift+Enter</kbd>) opens it in a new window.
   - <kbd>⌥Enter</kbd> (<kbd>Alt+Enter</kbd>) opens it next to this tab, in a Split.

## Details

- The line under the list shows which of these keys work on the selected
  row.
- On an open tab's row, every key but <kbd>⌥Enter</kbd> switches to that tab. <kbd>⌥Enter</kbd> puts
  that tab next to yours in a Split.
- When you're on a pin, a page from another site opens in a new tab,
  because a pin always stays on its own site.
- Pins and Favorites have no Split choice.
- In a Split, Enter loads the page in the pane you're using.
- The home page's search field takes the same keys.
