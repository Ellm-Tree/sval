---
title: Delete an agent's Workspace
description: Remove an agent's Workspace and its tabs, or choose when Sval deletes unused ones for you.
---

Each session of an AI app gets its own Workspace, so agent Workspaces add
up. You can delete an agent's Workspace yourself. Sval also deletes the
Workspaces no session has used for a while.

Claude Code finished comparing laptops last week, and you don't need those
tabs anymore.

## Delete one Workspace

1. Above your tabs, select the current Workspace's name.
2. Under **Agent Workspaces**, point to the agent's app, then to the
   agent's Workspace.
3. Choose **Delete Workspace…**.
4. In the dialog, select **Delete Workspace**.

## Choose when unused Workspaces go

1. Open Settings › Agents.
2. Under Agent access, choose a time in **Delete unused agent Workspaces**.

The choices are **After 7 days**, **After 30 days**, **After 90 days**,
and **Never**. The setting starts at After 30 days.

## Details

- Deleting an agent's Workspace leaves the app approved. The app's next
  session gets a new Workspace without asking you again.
- If a session comes back to a deleted Workspace, the session can't get the
  tabs back. It starts a new Workspace instead.
- Sval never deletes a Workspace a session is using, or one you've taken
  control of.
- Only the device that ran a Workspace's sessions deletes that Workspace
  for going unused.
- An agent can also delete its own Workspace. Sval tells agents to do that
  only when you ask or agree.
- To remove the app's approval and its site rules, unpair the app. See
  [Unpair an AI app](/docs/how-to/agents/unpair-an-ai-app/).
