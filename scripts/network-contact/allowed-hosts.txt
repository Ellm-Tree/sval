# Every host Sval may contact on its own (Sval spec §10.9).
#
# scripts/network-contact-test.sh launches Sval on a fresh profile, drives it,
# and fails on any host it resolved or connected to that is not listed here.
# scripts/network-contact-ios.sh does the same for the iPhone app in the
# simulator, from a packet capture.
# Pages the test loads itself are served from localhost and never count.
#
# Format: <host> <status> <reason>
#   allowed — decided and disclosed
#   pending — decided against, and still contacted until the change named in
#             the reason lands. The test passes and prints it, so it cannot be
#             forgotten.
#   opt-in  — contacted only once the user turns the feature on. Allowed in
#             the SVAL_NETWORK_ALL_SWITCHES run and the iPhone's
#             SVAL_NETWORK_STRICT run; a failure in the default run,
#             because there it would mean contact the user never chose.
