# Mozilla's own tests for the code Sval ships: the areas Sval's patches change
# and the Firefox features Sval keeps. One test per line, then any prefs it
# runs with, then a comment naming what it covers. scripts/upstream-tests.sh
# prints them for scripts/test.sh, one group per set of prefs, and CI's full
# Linux tier runs them, half of each group in each Linux half.
#
# A test here passes in Sval on Linux. A test of something Sval removes,
# locks or replaces on purpose is never listed; it goes in
# upstream-test-known-failures.txt with its reason, and a failure Sval
# causes by mistake is an issue.
#
# A test that fails only on a default a user can change runs with the user's
# other choice, so it proves that choice still works: <name>=<value>, and the
# comment names the control that sets it. @default@ in a value is Sval's
# default for that pref, so "@default@,-Target" is Sval's fingerprinting
# overrides with that target's switch turned off, as Gecko applies the
# tokens in order.
