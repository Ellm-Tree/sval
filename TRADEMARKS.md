# Sval's name and logo

Sval's code is open source (`LICENSING.md`), and anyone may fork it. Its name,
"Sval", and its logo and other brand art (`branding/sval/LICENSE`) are
Ellm Tree, Inc.'s, so that a build nobody at Sval made cannot present itself as
Sval. This is the policy for using them. Mozilla's trademark policy applies
the same rule to Sval as a modified version of Firefox.

1. **The code.** Anyone may fork Sval under its license. This policy covers
   only the name and the brand art.
2. **Unmodified builds** may be redistributed under the name and with the art,
   by mirrors and package managers among others.
3. **Linux distributions** may keep the name and art with build and
   integration patches, such as using system libraries or adding sandboxing,
   provided the browser behaves as Sval does.
4. **A modified version** takes its own name and replaces all of the brand
   art. It may say it is "based on Sval", alongside an equally prominent
   statement that it is not affiliated with Sval.
5. **Referring to Sval.** Anyone may use the name, and the unmodified logo, to
   refer to Sval itself: an importer's "Import from Sval", a list of
   compatible software, a review. Never as their own product's name or icon,
   or in a way that implies Sval endorses them.
6. **Updates.** A modified version uses its own update server and signing
   keys, never `download.sval.app`, so Sval's updates never overwrite it and
   its users never reach Sval's servers.
7. **Community use**, such as fan sites and groups, may use the name if it
   doesn't imply it is official. A domain name, an app store listing or
   merchandise for sale needs permission first.

For permission, or a use this does not cover, ask Ellm Tree, Inc. at
https://sval.app.
