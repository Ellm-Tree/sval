    Agent access

    Connect an AI app

    Connect adds Sval to the app's settings. Then restart the app. It can use Sval while agent access is on.

    GNOME brings every new window to the front, so when an AI app starts Sval, Sval opens over the window you're in. To keep it behind, run gsettings set org.gnome.desktop.wm.preferences focus-new-windows strict.

    Other apps

    Any app that runs local MCP servers can use Sval. Add a server named sval with this file as its command, or paste the JSON into the app's configuration. Then restart the app.
