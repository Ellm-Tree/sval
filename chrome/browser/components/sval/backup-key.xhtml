Back up your sync key

The sync key unlocks your synced Workspaces. Only your devices have the sync key. Keep a copy somewhere safe.

Keep the sync key in a password manager

  1. Press Copy.
  2. In 1Password, Bitwarden, Apple Passwords, or another password manager, make a secure note called “Sval sync key”. Paste the code into the note.
  3. If you lose every device, set up Sval on a new device. Choose the sync folder, then “Restore from a backup”.

You can also save the sync key to a file or print the sync key. Never keep the sync key in the sync folder.
