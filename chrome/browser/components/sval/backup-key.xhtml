Back up your sync key

This key unlocks your synced Workspaces. Nobody can recover it for you, not even Sval, so keep a copy somewhere safe.

Keep it in your password manager

  1. Press Copy.
  2. Make a secure note called “Sval sync key” in 1Password, Bitwarden, Apple Passwords, or another password manager, and paste the code into it.
  3. If you lose every device, set up Sval on a new one. Choose your sync folder, then “Restore with your backup key”.

You can also save it to a file or print it. Never keep it in your sync folder.
